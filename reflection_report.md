# Reflection Report

## Project Title

AI Study Assistant

---

## Objective

The objective of this project was to build an AI-powered web application using Streamlit, Groq API, and Prompt Templates. The application helps users ask questions and receive AI-generated answers from different expert roles.

---

## Project Description

I developed an AI Study Assistant where users can choose an expert role such as Teacher, Software Engineer, Career Counselor, Doctor, Java Professor, or Nutritionist. After selecting a role and entering a question, the application sends the prompt to the Groq API and displays the AI-generated response in a simple and beginner-friendly format.

---

## Technologies Used

- Python
- Streamlit
- Groq API
- Prompt Engineering
- python-dotenv
- Git & GitHub

---

## Challenges Faced

During this project, I faced several challenges:

- Installing and configuring Streamlit.
- Setting up Git and GitHub.
- Managing environment variables using the `.env` file.
- Fixing import errors related to `prompts.py`.
- Integrating the Groq API successfully.
- Uploading the project to GitHub.

---

## How I Solved Them

I solved these problems by:

- Installing the required Python libraries.
- Using `python-dotenv` to load environment variables.
- Debugging Python import errors.
- Configuring Git correctly.
- Following GitHub best practices for version control.
- Testing the application after every change.
