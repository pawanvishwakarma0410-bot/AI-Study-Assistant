# 📚 AI Study Assistant

## 📌 Project Overview

AI Study Assistant is a Streamlit-based web application that uses the **Groq API** and **Prompt Templates** to provide AI-generated answers. Users can choose different expert roles such as Teacher, Software Engineer, Career Counselor, Doctor, Java Professor, and Nutritionist to receive responses in the selected expert's style.

---

## 🎯 Objective

To develop a Streamlit application using Large Language Models (LLMs), Prompt Templates, and the Groq API that generates accurate and beginner-friendly answers based on the selected expert role.

---

## ✨ Features

- 🤖 AI-powered question answering
- 👨‍🏫 Multiple expert roles
- 📝 Prompt Template implementation
- 🔐 Secure API key management using `.env`
- 💻 Simple and interactive Streamlit interface
- ⚡ Fast responses using Groq LLM

## 🚀 Installation

### 1. Clone the repository

```bash
git clone https://github.com/your-username/AI-Study-Assistant.git
```

### 2. Open the project folder

```bash
cd AI-Study-Assistant
```

### 3. Install the required libraries

```bash
pip install -r requirements.txt
```

### 4. Create a `.env` file

```
GROQ_API_KEY=your_groq_api_key
```

### 5. Run the application

```bash
streamlit run app.py
```

## 📖 How to Use

1. Launch the application.
2. Select an expert role.
3. Enter your question.
4. Click **Generate Answer**.
5. Read the AI-generated response.
